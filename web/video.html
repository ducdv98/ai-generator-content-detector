How the marks work

File labels. An MP4 is a row of boxes: an index, the compressed frames, and optional extras. C2PA Content Credentials and the IPTC "AI-generated" tag are extra boxes. Every platform re-encodes uploads, which builds a new file from the frames alone, so the label rarely reaches a viewer.

Frame watermark. The keyed image watermark from step two, added to every frame with the same pattern. Because the pattern never changes, no timing has to be recovered: any surviving frames carry the whole mark, and averaging frames sharpens it a little. Its enemy is the codec, which is built to throw away exactly this kind of faint fine detail.

What vendors deploy (not runnable here). Google applies SynthID to each frame of Veo video. Meta's open Video Seal trains an encoder and decoder against simulated codecs, and marks one frame in every few, copying that pattern to the frames between to save computing time. Sora clips have carried a visible moving badge plus Content Credentials. More detail and sources: docs/video-watermarking.md.
